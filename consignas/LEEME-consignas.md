# Enunciados a grabar (botón de bocina)

Cada bocina busca su audio en `consignas/{id_de_pantalla}.mp3`.
Grabá un archivo por cada fila y guardalo con ESE nombre exacto en esta carpeta.

| Nombre de archivo                      | Texto a grabar |
|-----------------------------------------|-----------------|
| screen-nivel1-play.mp3                  | Mirá el dibujo y tocá el botón una vez por cada sonido que tenga la palabra |
| screen-nivel2-play.mp3                  | Mirá el dibujo y tocá una vez por cada sonido |
| screen-nivel3-play.mp3                  | Mirá el dibujo y tocá el botón una vez por cada sonido |
| screen-nivel1-play2.mp3                 | Mirá el dibujo y tocá la letra correcta |
| screen-nivel2-play2.mp3                 | Mirá el dibujo y tocá la letra correcta |
| screen-nivel3-play2.mp3                 | Mirá el dibujo y tocá la letra correcta |
| screen-nivel1-play3.mp3                 | Arrastrá cada color sobre otro que empiece con la misma letra |
| screen-nivel2-play3.mp3                 | Arrastrá cada útil sobre otro que empieza con la misma letra |
| screen-nivel3-play3.mp3                 | Arrastrá cada animal sobre otro que empieza con la misma letra |
| screen-nivel1-play4.mp3                 | Tocá las imágenes que TERMINAN con el sonido N |
| screen-nivel2-play4.mp3                 | Tocá las imágenes que TIENEN el sonido S |
| screen-nivel3-play4.mp3                 | Tocá las imágenes que TIENEN el sonido L |
| screen-nivel4-play.mp3                  | Tocá una letra y escuchá su sonido |

Son 13 en total. Mientras no esté grabado alguno, al tocar esa bocina la app
muestra el mismo aviso de "todavía no tiene sonido grabado" — no rompe nada,
simplemente no se escucha.
